# Lab 1 Gradescope package — STAT 4207/5207

Students upload only `Lab1.Rmd` to Gradescope; HTML and PDF files are not submitted. Students should knit locally to verify that their code, tables, plots, and written responses render correctly. The assignment is worth 10 points: 8 points for named R objects and 2 points for written responses graded by a teaching assistant directly from the submitted R Markdown file. The autograder extracts R chunks with `knitr::purl()` and accepts equivalent statistical results using the existing tolerances.
